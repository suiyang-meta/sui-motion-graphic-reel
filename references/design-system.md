# design system （style brief）

每个专案一份，开做前写好，放在专案根目录叫 `design-system.md`。之后每一幕只准用这里写的东西；要加新的颜色、字、做法，先回来改这份。

**这里装的是口味，全部可以换。** 下面四份范例只是起手：A 是作者自己那支片用的，B 是另一支片用的相反路线，C 是别的口味（暖色手作）的一次实测，D 是空白。拿哪一份都行，也可以都不拿。

## 栏位

| 栏 | 写什么 | 没想法时 |
|---|---|---|
| 气质 | 一句话：这支片要让人觉得怎样 | 问用户，或看他给的参考 |
| 参考 | 一到三个连结 / 图，各写一句「学它的什么」 | 可以空 |
| 画布 | 尺寸、帧率、片长大约多少 | 直式短片 1080×1920、30fps |
| 色板 | 底色 · 字色 · 强调色（各一个色码）。要第四色要写理由 | 三色以内 |
| 质感 | 平涂 / 渐层 / 发光 / 颗粒 / 阴影，各写「用」或「不用」 | 照气质选：冷静的少用，手作感的通常要一层很淡的纸颗粒。每一样「用」都写一句用在哪 |
| 字 | 标题字体、内文字体、小字（注记、数字）字体；字级层级（最小不小于多少） | 照气质选一个有性格的标题字（黑体冷静、宋体有笔锋、圆体亲切）+ 一个安静的小字 |
| 网格与安全边 | 用什么当版面的骨架（栏线、横格线、同心圆…）、左右留多少、上下哪些区域不放字（平台介面会盖住的地方） | 左右各留 90px；骨架照气质选 |
| 签名元素 | 贯穿全片的那一层东西。从题材里长出来：这个题材的人平常会看到什么记号、表格、工具？ | 见范例 A（设计软件的注记）与范例 C（冲泡记录本的刻度与时间戳） |
| 动的性格 | 弹（过冲回弹）/ 稳（慢起慢停）/ 硬（逐格、硬切），以谁为主 | 弹为主，像素与数字用硬 |
| 角色 | 有没有、图在哪、可以怎么动 | 没有就不要临时画一个 |
| 声音 | 配音的人声、语速、有没有配乐与音效 | 见 `engines.md`「配音」 |
| 不要 | 这支片不准出现的东西 | 见各范例 |

## 范例 A · 深色瑞士网格（作者那支 15 秒片的定稿）

对比图：`../examples/v4-unified.jpg`、`../examples/v7-near-final.jpg`。

- **气质**：冷静、精准、把做工摊开给你看。主角是字和几何形状，不是特效。
- **参考**：动态设计师的作品集片头。学「少色 + 网格 + 粗字配细线 + 形状变形」。
- **色板**：夜黑 `#0D0C10` · 纸白 `#F3F0EA` · 红 `#FF3B30`。
- **质感**：全部平涂。不用渐层、不用发光、不用彩色光斑、不用颗粒。景深用透视和视差做。
- **字**：一个粗黑标题字 + 一个等宽小字（注记、数字）。大标题约画面宽的 1/11，画面上任何字不小于 24px。
- **网格**：12 栏细线网格当远景；左右各 90px 不放字。
- **签名元素**：设计工具的注记层 —— 选取框 + 八个把手、形状名称与尺寸标签（`RECT_01 · 110×640`）、贝兹把手、底部一条关键帧轨道（菱形 + 红色播放头 + 帧数）。小、对齐网格、跟着主角动。
- **动的性格**：字和形状用弹簧（落地压扁回弹）；像素用逐格；镜头用慢起慢停。
- **角色**：一个像素小人，只在像素段和收尾出现，逐格动、不旋转。
- **声音**：一个男声，整段一次生成后整条加速到 1.4 倍（作者的习惯：短片里正常语速听起来拖）。音效用程式合成，人声永远在最前面。
- **不要**：合成波 / 霓虹 / 粉紫渐层 / 发光；四个角的录制取景框；每一幕换一套配色；同一个画面里两个角色做同一个动作。

## 范例 B · 浅色渐层 SaaS（同一位作者的另一支片）

放这一份是为了说明：范例 A 的「不用渐层」是那支片的口味，不是真理。这一支就用了渐层，而且是用户自己挑的。

- **气质**：明亮、现代、像一家设计很好的软件公司的官网。
- **色板**：近白底 · 深蓝灰字 · 一组紫到橘的品牌渐层（只用在大块背景与一个主要按钮上）。
- **质感**：渐层用（大面积、柔和）；玻璃卡片用（半透明 + 细边）；发光不用；颗粒不用。
- **字**：一个几何无衬线体，粗细对比大。
- **签名元素**：圆角卡片 + 很细的投影；每一幕一个不同的手法当主视觉（剪纸拼贴 · 真 3D 小场景 · 玻璃卡片 · 超大 kinetic 字）。
- **动的性格**：稳为主（慢起慢停），标题用弹。
- **不要**：故障风（glitch）；在 3D 场景里塞 2D 像素角色；为了填满画面下半部泼一层装饰。

## 范例 C · 暖色手作（别的口味的一次实测）

这一份不是作者的片。它是拿一台什么都不知道的 AI、只给这份 skill，替一家虚构的咖啡店做 15 秒冷萃介绍的实测结果，放在这里是为了让你看到「换了口味以后，同一套手艺长什么样」。图：`../examples/other-taste-warm-handmade.jpg`。

- **气质**：像一本手写的冲泡记录本被慢慢翻开。温暖靠颜色与纸感，高级靠留白和克制。
- **色板**：深咖啡 `#24170F` · 米白 `#F1E7D6` · 橘铜 `#C77A3E`。中间一幕反白（米白底），还是同三色。
- **质感**：平涂用；颗粒用（全片一层很淡的纸颗粒）；渐层、发光、阴影不用。
- **字**：粗宋体当标题（有笔锋）+ 等宽小字（时间戳、刻度）。
- **骨架**：很淡的横格线（记录本），不用方格网。
- **签名元素**：细铜线、刻度、时间戳，加一条贯穿全片的底部「冲泡记录」轨道：片子走 15 秒，轨道上的计时走完 18 小时。
- **动的性格**：稳为主；大字落地只轻轻弹一下；计数硬跳。
- **四幕四种做法**：大字落地压扁 → 刻度环上数字滚到 18 → 一滴水变成圆形遮罩打开、杯子一笔一笔描出来、粉末沉降 → 镜头往后拉，整幕缩进瓶身标签里。
- **不要**：可爱卡通、蒸汽（这是冷萃）、霓虹发光、每幕换配色。

照实讲它的完成度：全片统一、每幕换做法、转场有看点都做到了；但每一幕的层次比范例 A 的定稿薄（前景与资讯层东西少），没有真 3D，有一处镜头推进时把左边的小字带出了画面。所以它是「这份 skill 的起点长这样」，不是天花板。

## 「不要」清单怎么写

写具体看得出来的东西，不写形容词。「不要俗」没有用；「不要粉紫渐层、不要发光描边、不要透视网格地板」才查得出来。

用户每否决一样东西，就加一行进他的「不要」清单，并且写上是哪一版、他怎么说的。这张清单是这个专案最值钱的东西：下一支片从第一版就不会再犯。
