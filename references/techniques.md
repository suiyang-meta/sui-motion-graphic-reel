# 手法词汇表

叫得出名字，就叫得动。跟 AI 讲「做得酷一点」它只能猜；讲「开场用 fly-in，落定时字做 squash」它就知道要写什么。

每个手法四栏：**名字**（业界叫法）· **长什么样** · **怎么跟 AI 讲**（可以直接贴）· **常见做坏**。

## 字

| 名字 | 长什么样 | 怎么跟 AI 讲 | 常见做坏 |
|---|---|---|---|
| Kinetic typography（动态文字） | 字本身在演：弹、压、拉、逐字进场 | 「所有大字都要 kinetic：落地压扁、弹起拉长、弹性回弹、逐字错开，不要只有淡入」 | 只有淡入或遮罩平推 |
| Squash & stretch（压扁与拉长） | 掉下来越掉越长，落地瞬间压扁、撑宽，再弹回 | 「字掉下来时纵向拉长，落地那一帧 scaleY 压到 0.6、scaleX 撑到 1.3，再用衰减的余弦弹回，变形原点放在字的底部」 | 原点在中心，看起来像呼吸不像落地 |
| Stagger（逐字错开） | 一行字不是同时出现，每个字晚 0.03–0.06 秒 | 「逐字错开 0.05 秒进场」 | 错开太久，念完了字还没到齐 |
| Stretch-in（拉伸进场） | 字从横向拉长 2–3 倍弹回原样 | 「这个词横向拉长 2.6 倍进场，用弹簧回到 1」 | 相邻字母叠在一起太久 |
| Squash-out（压扁退场） | 先往上拉长一点（预备动作），再压成一条线消失 | 「整段退场：先预备拉长 3%，再压成一条线」 | 预备动作太大，冲出自己的区域 |
| Mask reveal（遮罩推出） | 字在自己的格子里从下面被推上来 | 「每个字在自己的格子里被遮罩推上来」 | 整支片的字都只用这一招 |
| Word sync（对字） | 念到哪个词，那个词的画面在那一帧到场 | 「元素绑在配音逐字时间上：念到『粒子』那一帧粒子才出现」 | 用猜的秒数，配音一改全部对不上 |
| Karaoke 字幕 | 字幕整句在，念到的字点亮 | 「字幕照逐字时间点亮，一帧硬切，不要淡入」 | 字幕颜色比主体还抢眼 |

**弹簧公式**（位置从 0 到 1，可以直接用帧数算，不用模拟）：

```
x(t) = 1 − e^(−ζωt) · ( cos(ω_d·t) + (ζω/ω_d)·sin(ω_d·t) )      ω_d = ω·√(1−ζ²)
```

ζ（阻尼）小就弹：0.3 会明显过冲回弹，0.6 只弹一点，1 不弹。ω 越大越快。

## 形状

| 名字 | 长什么样 | 怎么跟 AI 讲 | 常见做坏 |
|---|---|---|---|
| Shape morph（形状变形） | 一个形状顺顺地变成另一个：圆 → 方 → 星 → 三角 | 「一个强调色形状当主角一路变形。每个形状都用同样数量的点表示（同一组角度上的半径），点数一样才变得顺」 | 两个形状点数不同，中间会扭成一团 |
| Assemble（零件拼合） | 几个几何零件滑进来拼成一个字或图 | 「『15』由 6 个几何零件拼成，第 0 帧就已经拼到八成，还在滑回原位」 | 第 0 帧零件太散，看不出是什么 |
| 注记层（annotation layer） | 像设计软件一样的选取框、把手、名称标签、关键帧轨道跟着主角 | 「叠一层设计工具注记：选取框 + 八个把手、形状名称与尺寸、关键帧轨道。小、对齐网格、跟着动作动」 | 注记比主角大；或做成四角取景框挡画面 |

## 镜头

| 名字 | 长什么样 | 怎么跟 AI 讲 | 常见做坏 |
|---|---|---|---|
| Fly-in（飞入） | 镜头从很远的地方往前飞，穿过几层前景，落定在主角前 | 「开场不要原地出字：镜头从远处 fly-in，穿过几层前景（近的要大、要从镜头两侧掠过），落定那一刻字才压扁回弹」 | 飞 0.4 秒就停，后面 3 秒不动 |
| Pan / truck（横移） | 镜头移到旁边另一个场景，两个场景同时在画面里一小段 | 「下一句镜头横移到旁边另一个区域，远近层移动速度不同」 | 其实是整个画面滑走换一张，没有视差 |
| Parallax（视差） | 远的东西动得慢，近的动得快 | 「远、中、近三层用不同速度移动」 | 三层同速，等于一张平面图在滑 |
| One-take（一镜到底） | 整支片像同一个镜头在一个连续的世界里走 | 「把每一拍的画面摆在一块大画布上不同的位置，镜头在它们之间流动，停在每一拍上；不要硬切」 | 所有停点叠在同一个位置，用淡入淡出冒充 |
| Motion blur（动态模糊） | 镜头走得快的那几帧画面糊一下 | 「镜头移动速度超过某个值时整块画布加模糊，字幕不糊」 | 停住了还糊 |
| Orbit（环绕） | 真 3D 里摄影机绕着主体走弧线 | 「摄影机写成关键帧：偏航角、半径、高度、看向哪、视角，每段慢起慢停插值，走弧线不走直线」 | 把 2D 放大当推进 |
| Rack focus / 景深 | 焦点外的东西糊掉 | 「离焦点越远越糊、越淡」 | 用在平涂风格里显得脏（看 design system 要不要） |

## 转场

| 名字 | 长什么样 | 怎么跟 AI 讲 | 常见做坏 |
|---|---|---|---|
| Push-through（穿梭） | 镜头推进上一幕的一个小物件里，里面就是下一幕 | 「镜头推进角色衣服上的一格像素，那一格填满画面后碎开变成下一幕」 | 推进太快，认不出推进的是什么 |
| Match cut（形状对位） | 上一幕最后的形状 = 下一幕第一个形状 | 「粒子收成的那一点，就是下一幕的笔尖」 | 位置差几个像素，看起来像跳了一下 |
| Mask / iris（遮罩、光圈） | 从一个形状里透出下一幕，或一个圈打开 | 「从『字』的笔画里透出下一幕；笔画里要已经看得到下一幕在动」 | 透出来的那一幕还是空的，看起来像没效果 |
| Reveal（往后拉） | 镜头往后拉，原来刚才的画面只是更大场景里的一小块 | 「介面往后拉，原来是一圈五块萤幕里的一块，每块里的画面都还在动」 | 小块里的画面是静止截图 |
| Wipe（硬刷） | 一条色带扫过去换场 | 「换段用强调色色带硬刷，放在配音换句的空档」 | 每个转场都用它 |

## 不同题材的做法

| 名字 | 长什么样 | 怎么跟 AI 讲 |
|---|---|---|
| 像素逐格 | 角色一格一格跳，位置对齐像素格 | 「像素角色 12–15fps 跳格、位置对齐到整数格、不旋转不平滑缩放」 |
| 粒子（物理） | 一堆点炸开、落下、被吸回去聚成字 | 「粒子用重力抛物线散开，再用阻尼弹簧聚成字；写成解析式，给帧数就算得出位置」 |
| 粒子（流场） | 粒子像烟、像水一样卷 | 「粒子在无散度流场里流动（curl noise 这一类），有拖尾、有大小深浅变化」 |
| 手写字 | 一笔一笔照笔顺写出来 | 「照真实笔顺一笔一笔描（用公开的笔顺资料），镜头贴着笔尖走」 |
| 3D 介面 | 几块面板沿深度错开，镜头绕过去 | 「面板沿 Z 轴错开摆，镜头绕过去看得到侧面与前后关系」 |
| 计数 | 数字滚动到真值 | 「数字从 0 滚到真值停住，每跳一下压扁一下。开场第 0 帧不要放还没滚到的假数字」 |
| 介面示范 | 画面里的 App 在被操作 | 「介面要会动：游标移过去、选单打开、字一个个打出来、回覆逐行出现。不要只贴一张静态截图」 |

## 节奏

| 名字 | 意思 | 怎么跟 AI 讲 |
|---|---|---|
| Hold（停住） | 每一拍主体停住让人读 | 「每一拍的主体到位后完全停住，至少停到那一句念完；背景可以继续慢动」 |
| Anticipation（预备动作） | 大动作前先往反方向缩一下 | 「起跳前先蹲 2–3 帧」 |
| Overshoot（过冲） | 冲过头再弹回来 | 「到位时过冲 8% 以内再弹回」 |
| Ease（缓动） | 慢起慢停，不是匀速 | 「镜头用慢起慢停；元素进场用快进慢停」 |
| 两波开场 | 前 4 秒要有两次大动作 | 「0–1 秒一波大位移，1.5–4 秒再一波」 |
